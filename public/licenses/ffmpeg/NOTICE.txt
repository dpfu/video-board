Changes: TypeScript typed-array interface; reusable previous-frame storage;
8–16 bit tightly packed sample planes; no FFmpeg filter framework, codec or SIMD code.

The port is licensed under LGPL-2.1-or-later, retaining the upstream terms.
See COPYING.LGPLv2.1 in this directory. The production build also includes the
complete port source as licenses/ffmpeg/scdet.ts. The repository contains its
build configuration and lockfile for rebuilding with a modified port.

Browser resizing/luma conversion, shot-range selection, UI and application
integration are separate Video Board code under the repository's MIT license.
This is a cut-detector port, not an FFmpeg codec bundle.
